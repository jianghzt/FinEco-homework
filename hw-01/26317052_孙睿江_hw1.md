# 一页研究计划：A股行业动量策略的边界与实务应用

## 任务
在写大量代码之前，检查问题、数据与方法能否衔接。本计划重点作出有理由的选择，后续再用数据检验和修订。

## 一页模板

| 项目 | 需要写清楚的内容 |
| :--- | :--- |
| **问题** | 近十年（2015-2025）A股申万一级行业的动量效应，在全样本、不同市场状态（牛/熊/震荡）及不同板块（周期/消费/成长/金融/稳定）内部是否存在显著差异？反转效应在何处占据主导？ |
| **目标** | 在月度调仓、单行业权重上限（20%）的约束下，构建基于历史量价数据的行业动量策略，并与行业等权基准进行对比，寻找动量的“适用边界”，为实务中的行业轮动提供可操作的建议。 |
| **数据** | 来源：Wind/国泰安/Akshare。观测单位：行业-月。频率：月度。样本范围：2015年1月至2025年12月，包含31个申万一级行业指数的月度收盘价与成交量。 |
| **变量** | 1. 核心变量1（信号）：过去N个月（1、3、6、12个月）的行业累计收益率。2. 核心变量2（目标）：下个月的行业收益率。3. 分组变量：市场状态（沪深300的200日均线划分牛/熊/震荡）、板块属性（上游周期/中游制造/下游消费/大金融/TMT）。 |
| **基准方法** | 排序分组法（Sorting）。按过去N个月收益排序，在板块内部做多前30%行业，做空后30%行业（或仅做多前30%对比全行业等权）。理由：最经典透明，完全依赖量价数据，避免财务数据缺失问题。 |
| **评价** | 1. 样本外检验：2015-2020训练，2021-2025验证。2. 摩擦检验：扣除双边0.1%-0.15%的交易成本。3. 推翻原结论的证据：如果控制板块效应后，动量组合的Alpha不再显著；或者在某些板块（如金融）呈现出强烈的“反转效应”且稳定，则推翻“行业动量普遍有效”的结论。 |
| **执行** | 第一步：Agent提取申万一级行业与沪深300月度数据并清洗。我检查：价格断点、行业分类变更。第二步：Agent计算1/3/6/12个月动量因子并排序分组。我检查：有无未来函数、调仓时点。第三步：Agent按板块及市场状态Groupby循环回测并输出统计表。我检查：是否符合金融直觉，提炼结论。 |
